# CCNA Security Labs

Hands-on network security projects I built while studying for the Cisco CCNA. Each lab includes the topology, full device configurations, verification evidence, and a security test that shows the defence working against a simulated attack.

| # | Project | Tools | Status |
|---|---------|-------|--------|
| 1 | [Secure Small Office Network](01-secure-office/) | Cisco Packet Tracer | In progress |
| 2 | [Zone-Based ACL Firewall](02-acl-firewall/) | Cisco Packet Tracer | In progress |
| 3 | [Site-to-Site IPsec VPN](03-ipsec-vpn/) | Packet Tracer, GNS3 | Planned |
| 4 | [Attack and Defend Lab](04-attack-defend/) | GNS3, Kali Linux | Planned |
| 5 | [Python Security Audit Script](05-python-audit/) | Python, Netmiko | Planned |

## Skills covered
VLANs and trunking, inter-VLAN routing, DHCP, SSH and AAA, port security, DHCP snooping, Dynamic ARP Inspection, BPDU guard, ACLs, IPsec VPNs, Layer 2 attack mitigation, network automation.
